UI/UX Diagnosis: 8 Screens

My assessment of what each screen needs — click to agree or disagree with any classification

Needs UX Redesign

Structure/flow problems — not just visual

1

Login Screen — Redesign

Issues: Generic auth form with no brand identity. Just "LeadForge" text + subtitle + fields. No visual hook, no trust signals, no value proposition. The pill toggle (Sign In/Sign Up) works but the overall page feels like a template. First impression of the app — needs to sell.

Proposed: Add brand presence (icon/illustration), social proof or value props, better visual hierarchy. Make it feel like a product, not a code exercise.

2

Onboarding — Redesign

Issues: 4 feature pages with just icon + title + description is the most generic onboarding pattern. No visual differentiation between pages (same layout, different icon). Profile setup page (page 5) is disconnected from the feature tour. Dot indicators are tiny and hard to see.

Proposed: Richer illustrations or mockup previews per feature. Progress indicator that shows journey. Smoother transition from "learn" to "setup" phase.

3

Activity Screen — Redesign

Issues: This is just a list of businesses sorted by date, not a real activity feed. It shows businesses grouped by time (Today/This Week/Earlier) but doesn't show WHAT happened — "Found", "Audited", "Demo created" are generic labels, not events. The "featured" card for Today's first item adds visual weight but not information. Empty state is weak.

Proposed: True event-based timeline with verbs ("You audited...", "Demo generated for..."). Rich cards with contextual actions. Better empty state with onboarding.

4

Business Detail — Redesign

Issues: This is the most important screen in the app but reads as a long vertical scroll of disconnected sections. Contact links (Call/Website/Maps) are flat text that's easy to miss. The flow from Audit → Demo → Outreach has no visual journey/stepper. Audit result, AI Analysis, Demo status, and Outreach status all look like different UI languages. No clear "what to do next" guidance.

Proposed: Visual workflow stepper (Audit → Demo → Outreach). Unified card styles. Prominent contact section. Clear next-action CTA at each stage.

Needs Visual Polish

Structure is fine, just needs to look/feel better

5

Dashboard "Getting Started" — Polish

Issues: The 3-step guide is clear but visually flat. No step numbers, no progress feeling, the "Start Scouting" button blends in. Steps lack visual connectors between them.

Proposed: Numbered steps with visual connector line. Better contrast for the CTA. Maybe a dismissible card wrapper so it doesn't linger forever.

6

Pipeline — Polish

Issues: Structure is solid (funnel bar + collapsible sections + swipe actions). But the sections feel like plain lists with no visual weight. The "Needs Action" card is good but business cards within sections are bare (just name + address + score + chevron). No status colors on individual items.

Proposed: Status color accents on section headers/items. Richer business cards with status badges. Better visual separation between sections.

7

Build Demo — Polish

Issues: The data summary chips and custom instructions field work well. But the overall layout is centered text that feels like a wizard without visual grounding. The "AI WILL USE THIS DATA" section is informative but doesn't feel exciting for what's essentially a "build me a website" action.

Proposed: More visual excitement before generation. Better visual hierarchy between data preview and CTA. The preview screen (WebView) is fine.

8

Outreach — Polish

Issues: (As seen in your screenshot) Flat layout, excessive whitespace below, channel/tone/language chips are functional but have no visual personality. The sections (Channel, Tone, Lang) feel crammed together without rhythm. No preview of what the business looks like before generating.

Proposed: Business context card at top. Better section spacing and grouping. More visual personality on the channel chips (color coding per channel). Fill the empty space with helpful context.

9

Settings — Polish

Issues: The profile card with left accent border looks good. Usage pills are well-designed. But the Preferences section uses CupertinoListSection which is native iOS but clashes with the custom design language of the rest of the app. The sign-out section feels disconnected.

Proposed: Custom preference cards matching app design language instead of native CupertinoListSection. Better visual flow from usage to preferences to account actions.

Priority Recommendation

Batch 1 (highest impact): Login + Onboarding + Business Detail — these are the first impression, the core workflow, and the most-used screen.

Batch 2: Outreach + Build Demo + Pipeline — the revenue-driving features that need to feel premium.

Batch 3: Activity + Settings + Getting Started — supporting screens.
